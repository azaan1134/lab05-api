## 1. Туршилтын зорилго ба функц

- **Оролт:** `studentID`, `courseID`
- **Гаралт:** Статус код + `result`

## 2. Сонголтууд ба төлөөлөх утгууд (Даалгавар 2)

| Параметр | Сонголт | Эквивалент анги (төлөөлөх утга) |
| :--- | :--- | :--- |
| **studentID** | Хүчинтэй байдал | • **Идэвхтэй** оюутан (`status: "active"` )<br>• **Идэвхгүй** оюутан (`status: "inactive"`)<br>• **Байхгүй** оюутан (PUT хийгээгүй ID) |
| **studentID** | Үзсэн хичээлүүд (урьдач нөхцөл хангах эсэх) | • **Хангана** (`coursesTaken: ["CS201"]`)<br>• **Хангахгүй** (`coursesTaken: []`) |
| **courseID** | Хүчинтэй байдал | • **Байгаа** хичээл<br>• **Байхгүй** хичээл |
| **courseID** | Урьдач нөхцөл | • **Бүгд үзсэн**<br>• **Огт үзээгүй**<br>• **Зарим нь үзсэн** (`["CS201", "CS202"]`-аас зөвхөн CS201) |

> **Тооцоолол ба хасагдах хослолууд:**
> * Боломжит хослол: $3 \times 2 \times 2 \times 3 = 36$
> * **Хасагдах хослолууд:**
>   * Байхгүй оюутанд "урьдач хангах эсэх" сонголт утгагүй;
>   * Байхгүй хичээлд "урьдач нөхцөл" сонголт утгагүй.
> * Үүнээс гадна хүснэгтэд ороогүй оролтын формат (талбар дутуу, буруу JSON) нь тусдаа хязгаарын тохиолдол болно.
