\## Лекц 5-ын 5 алхам



\*\*1. Бие даан тестлэгдэх функц:\*\* `POST /registrations` — "хичээлд бүртгүүлэх". Оролт: `studentID`, `courseID`; гаралт: статус код + `result`.



\## 2. Сонголтууд ба төлөөлөх утгууд (Даалгавар 2)



| Параметр | Сонголт | Эквивалент анги (төлөөлөх утга) |

|---|---|---|

| studentID | Хүчинтэй байдал | \*\*Идэвхтэй\*\* оюутан (`status:"active"`) · \*\*Идэвхгүй\*\* оюутан (`status:"inactive"`) · \*\*Байхгүй\*\* оюутан (PUT хийгээгүй ID) |

| studentID | Үзсэн хичээлүүд (урьдач нөхцөл хангах эсэх) | \*\*Хангана\*\* (`coursesTaken:\["CS201"]`) · \*\*Хангахгүй\*\* (`coursesTaken:\[]`) |

| courseID | Хүчинтэй байдал | \*\*Байгаа\*\* хичээл · \*\*Байхгүй\*\* хичээл |

| courseID | Урьдач нөхцөл | \*\*Бүгд үзсэн\*\* · \*\*Огт үзээгүй\*\* · \*\*Зарим нь үзсэн\*\* (`\["CS201","CS202"]`-аас зөвхөн CS201) |



Боломжит хослол: 3 × 2 × 2 × 3 = 36. Боломжгүй хослолууд (хасагдана):

\- Байхгүй оюутанд "урьдач хангах эсэх" сонголт утгагүй;

\- Байхгүй хичээлд "урьдач нөхцөл" сонголт утгагүй.



Үүнээс гадна хүснэгтэд ороогүй оролтын формат (талбар дутуу, буруу JSON) нь тусдаа хязгаарын тохиолдол.
